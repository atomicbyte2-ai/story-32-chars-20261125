# Tell a Whole Story in 32 Characters

> He took the dog, I kept the WiFi

A breakup told as a divorce settlement in one Wi-Fi name: he walked off with the dog, the narrator kept the Wi-Fi — and sounds perfectly happy with the trade. The setup (a split, a dog) and the punchline (the Wi-Fi was the real prize) land in a single glance at a phone's network list.

`main.ts` holds the line as a constant, validates it (1–32 characters, a single line, no control characters, not only whitespace), then writes it with no trailing newline to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`), creating the directory if needed, and logs the character count.
